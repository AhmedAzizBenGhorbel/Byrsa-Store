# Byrsa Store Database Project

Database project for Byrsa Store, prepared as a semester-end submission.

## Contents

- `SQL/Byrsa-1-creation-tables.sql`: database table creation script
- `SQL/Byrsa-2-inserts.sql`: sample data insertion script
- `SQL/Byrsa-3-updates.sql`: update queries
- `SQL/Byrsa-4-requetes-simples.sql`: simple queries
- `SQL/Byrsa-5-requetes-avancees.sql`: advanced queries
- `SQL/Byrsa-6-creation-vues.sql`: view creation scripts
- `MEA/MEA-Byrsa.loo`: conceptual/entity-association model
- `Projet Base de données - Byrsa Store - Ben Ghorbel Ahmed Aziz - L2-DSI-EAD Promo 10.pdf`: final project report

## Suggested Execution Order

Run the SQL files in numeric order, starting with table creation and inserts before executing updates, queries, and views.
